# 架构与能力边界

MCP Gateway 是基于 FastAPI 和 FastMCP 的工具网关。它加载本地可信 Python 插件，将工具按组映射到 `/{group}/mcp`，当前没有远程 MCP 服务器聚合功能。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `backend/gateway/app.py` | 应用生命周期、管理路由、健康检查、HTTP 诊断 |
| `catalog.py` / `cli.py` | 插件发现、制品指纹、工具目录同步、管理员命令 |
| `service.py` / `contracts.py` / `models.py` | 写入校验、引用关系、版本控制、持久化 |
| `auth.py` / `credentials.py` | 管理员会话、凭据校验、组入站认证 |
| `mcp.py` | 请求快照、动态 Provider、配置注入、执行超时和线程容量 |
| `sdk/gateway_sdk/` | ToolPackage、ToolRuntime 和依赖注入契约 |
| `frontend/` | 管理控制台，通过管理 API 操作资源 |
| `plugins/` | 业务工具及上游服务适配，不由网关核心导入特定业务包 |

PostgreSQL 保存管理员、工具目录、组、绑定、配置集、加密密钥、认证配置、访问密钥摘要、审计和制品指纹。Redis 保存管理会话及登录限流，不缓存 MCP 组权限。插件在网关进程中执行，没有沙箱。

## 资源关系

- 工具来自插件代码，稳定 ID 为 `package.tool`；代码同步后进入目录，不自动发布到任何组。
- 组 ID 决定路由。组可关联一个认证配置；没有关联时为公开模式。新组默认禁用。
- 绑定连接组与工具，设置客户端可见名称、配置集、覆盖值及启停状态。同组工具 ID 和暴露名称分别唯一。
- 配置按模型默认值、配置集、绑定覆盖值进行浅合并；`$secret` 引用解密后只注入本次调用。
- 访问密钥属于一个组，用于 static 入站认证；上游密钥由工具配置或具体插件输入协议提供，二者独立。

只有组启用、绑定启用、工具全局启用且代码可用时，工具才能通过该组调用。禁用组返回 404；其他条件不满足的工具不会列出。所有管理员拥有相同权限，组隔离不等同于管理端多租户隔离。

## MCP 请求流程

1. 校验路径和来源，在 PostgreSQL REPEATABLE READ 事务中读取组、认证配置、绑定、目录和所需密钥。
2. 组不存在或被禁用时拒绝请求；公开和静态模式在快照事务内完成认证。OAuth 所需数据先读取，远程校验在事务释放后进行。
3. 为有效绑定构造工具及其配置副本，设置请求上下文。Provider 只向本次请求提供该组工具。
4. FastMCP 校验业务参数并执行工具，注入 ToolRuntime。异步工具使用异步任务；同步工具受每 worker 容量限制。
5. 返回结果或脱敏错误，记录请求编号、工具和耗时。正在执行的请求继续使用已读取快照，配置更新对后续请求生效。

传输配置为无状态 Streamable HTTP，使用 JSON 响应，无需 worker 粘滞。工具超时包含排队；已开始的同步线程不能强制终止，也无法撤销上游副作用。详见[插件契约](plugins.md)。

## 代码与配置的生命周期

管理 API 修改组和绑定等配置后无需重启。插件代码则在应用创建时加载；加载器仅执行 `<插件根目录>/*/plugin.py`，指纹覆盖根目录内所有 `.py` 文件的相对路径和内容，不包含 Markdown 或 JSON/YAML 资料。

`plugins check` 导入并验证本地工具，不访问数据库，也不列出全部工具名称。`plugins sync` 在一个事务中更新目录和指纹、验证有效绑定。应用启动和 readiness 检查本地指纹与数据库是否一致。删除插件代码后同步会保留历史工具和绑定，标记 `available=false`。

业务插件可以与主体一起打包，但不是主体的必需业务依赖。默认镜像复制整个 `plugins/`；仅保留所需插件的部署方法见[插件目录](../plugins/README.md)。不支持通过 Web 上传或热加载任意代码。
